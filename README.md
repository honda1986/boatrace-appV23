# boatrace-appV23

ボートレースの1着確率・3連単の予想と、勝負レースの成績・収支を見るアプリ。

アプリ: https://honda1986.github.io/boatrace-appV23/yosou/

## 画面

- **レース** … 日付を選んで、その日の全レースの予想と結果を見る(◀ ▶ で前後の日へ)。
  場ごと / 時刻順の切り替え、🔥勝負・◎上位10・未確定の絞り込み、次の勝負レースの案内。
- **収支** … 期間(7日 / 30日 / 今月 / 全期間)ごとの勝負レースの収支・回収率・的中率、
  累積収支のグラフ、カレンダー、月別・場別、勝負レースの明細、予想の精度(予想した確率と実際の割合)。

収支は記録した買い目と金額で、**実際の払戻金**から計算する。
買い目に出る「当たれば」は取得時点のオッズでの目安で、締切までに下がることが多い。

## ファイル

| ファイル | 中身 |
|---|---|
| `yosou.py` | 予想を作る。15分おきに回る(`.github/workflows/yosou.yml`) |
| `history.py` | 日別ファイルから成績・収支を集計する。`--backfill` で git の履歴から過去の日を復元 |
| `yosou/index.html` | アプリ本体 |
| `yosou/data.json` | いまの日の予想(`days/` の最新と同じ中身) |
| `yosou/days/YYYYMMDD.json` | 日別の予想と結果 |
| `yosou/history.json` | 日別の集計・勝負レースの明細・較正 |

過去の日が抜けたときは、Actions の「過去の予想を復元」を手動で1回まわす
(git の履歴に残っている `data.json` から `days/` を作り直す。既にある日は書き換えない)。
